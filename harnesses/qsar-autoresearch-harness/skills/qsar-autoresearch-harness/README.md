# QSAR coordination skill

Install all sibling skills in the QSAR pack. Read SKILL.md for orchestration and references/agent-skills.json for exact assignments. Shared methods are in ../qsar-autoresearch; focused methods are in the eight qsar-* stage skills.

Validate from this folder with `node scripts/validate_skill_map.js` or `./scripts/validate_harness.ps1`. Use `--dispatch training` or `--review training` on the Node script for minimal dispatch templates. This validates packaged wiring, not runtime review authenticity or scientific performance.
