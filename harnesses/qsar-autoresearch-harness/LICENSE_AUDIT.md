# License Audit - QSAR Autoresearch Harness

This harness ships prompt text, reference notes, and validation scripts under Apache-2.0 as part of AAAlab.

The harness may direct downstream workspaces to use external runtime dependencies such as:

- Python
- pandas
- scikit-learn
- openpyxl
- RDKit
- matplotlib or plotly for optional richer visualization

These dependencies are not bundled in this repository. Users must install them separately and comply with their upstream licenses.
