# 보고서·논문 기준

## 남길 내용의 기준

독자가 목적·근거·결과·판단을 이해하는 데 필요한 내용을 쓴다. 관련 용어나 사업명이 낯설면 짧게 설명하고, 연구 공백이나 차별점을 주장하면 무엇이 부족하고 무엇이 다른지 근거를 제시한다. 간결함을 이유로 필요한 설명·수치·방법·출처를 생략하지 않는다.

작성 도구, 파일 처리, 내부 검증, 작업 순서 등 작성자의 작업 디테일은 제출 목적에 필요할 때만 넣는다. “요청하신 대로 작성했습니다” 같은 대화 문구와 지시사항을 이행했다는 설명은 본문에서 뺀다.

## 문장과 근거

- 책임 회피를 위한 상투적 면책 문구와 내용 없는 방어적 설명을 넣지 않는다. 예: 근거 설명 없이 붙이는 “참고용이며 정확성을 보장하지 않습니다”.
- 해석에 영향을 주는 실제 불확실성·연구 한계·자료 범위는 남긴다. “한계가 있으므로 주의가 필요하다” 대신 어떤 자료가 빠졌고 어느 결론까지 가능한지 구체적으로 쓴다. 증거보다 강하게 단정하지 않는다.
- 같은 배경·조건·설명을 반복하지 않는다. 필요하면 한 번 설명한 뒤 해당 결과와 근거를 제시한다.
- 분량을 채우기 위한 배경·총평·실행 불가능한 제안을 추가하지 않는다. 요청한 분량·제출 양식 안에서 근거와 독자의 필요에 따라 내용을 배분한다.

## 면책성 문구와 자료 안내의 정리

면책성 표현은 “정확성을 보장하지 않는다”에 한정하지 않는다. 결과 뒤에 관성적으로 붙이는 “우월성이나 통계적 유의성을 주장하지 않는다”, “정확성을 입증하는 것은 아니다”, “하나의 성능 순위로 합치지 않는다”, “자료량 증가 자체를 성능 개선으로 해석하지 않는다”도 점검한다. 새로운 방법·조건·근거 없이 해석 금지만 덧붙인 문장은 삭제한다. 삭제한 문장을 다른 방어적 표현으로 바꾸어 되살리지 않는다.

- **본문에는 수행한 일과 관찰 결과를 쓴다.** 집단·평가 조건이 다르면 각각의 대상·방법·결과를 제시한다. 그 차이를 이미 설명했다면 “같이 비교하면 안 된다”는 총평을 반복하지 않는다.
- **구체적 한계는 필요한 위치에 한 번만 둔다.** 남기려는 문장에 대해 “삭제하면 어떤 결과나 평가 설계를 잘못 이해하게 되는가?”를 확인한다. 구체적인 오해를 짚을 수 없거나 앞의 방법·표에 이미 설명되어 있으면 삭제·통합한다. 필요한 사실은 부정형 경고 대신 해당 조건을 직접 기술한다. 예: “평가자료 일부를 모델 선정에도 사용했다.” 실제 검증 독립성·표본 범위가 달라지는 사실을 없애거나 독립검증으로 바꾸어 쓰지는 않는다.
- **제출 본문의 파일·시트 안내는 기본적으로 뺀다.** “○○.xlsx의 △△ 시트에 수록하였다” 같은 작업자료 위치, 내부 집계표 연결, 파일 판본 안내는 인계 기록이나 요청된 별도 자료로 분리한다. 학술 인용·원자료의 출처·제출 양식이 요구하는 첨부 참조는 유지하며, 내부 파일명을 삭제한다는 이유로 근거까지 지우지 않는다.
- **반복된 자료 처리 설명도 축약한다.** 복원·제외 이력, 후보 수와 실제 학습 수의 구분, 집합 간 중복 설명은 해당 방법이나 표에서 한 번 설명한다. 결과 뒤에서 같은 차이를 방어적으로 재설명하거나 과거 파일 이력을 늘어놓지 않는다. 현재 수치의 의미를 바꾸는 구분은 필요한 위치에 남긴다.
- **서로 다른 편집을 분리한다.** 면책성 표현 삭제, 자료 안내 삭제, 중복 설명 축약, 문단 병합, 수치 표시 변경을 같은 작업으로 취급하지 않는다. 문구 정리를 이유로 분모·성능·실행 임계값을 바꾸지 않는다. 표시 자릿수 변경도 실제 설정값 변경과 구분한다.

## 기존 원고 수정과 제출 전 점검

사용자가 직접 고친 글꼴 크기·여백·들여쓰기 등 서식을 보존한다. 분량에 참고문헌을 포함하는지는 제출 규정을 우선하고, 규정이 없으면 본문과 참고문헌을 구분해서 산정한다.

사용자가 수작업으로 고친 최종본이 있으면 그 파일을 후속 편집의 기준으로 삼는다. 삭제·축약한 문구를 이전 초안·분석 메모·자동 생성 코드에서 다시 가져오지 않는다. 최종본에 남아 있는 방법·조건까지 부정형 표현이라는 이유만으로 일괄 삭제하지 않는다. 새 근거로 꼭 필요한 정정은 삭제 문구의 복원과 구분해 구체적인 사실로 제시한다.

차이점 검토를 요청받으면 실제 파일 내용을 먼저 비교한다. 두 파일이 같다면 차이가 있다고 추정하지 않는다. 보존본으로 삭제 내역을 복원할 때는 비교 기준이 달라졌음을 명시한다. 검토·기준 정리만 요청받았으면 원고를 수정하지 않는다.

제출 전에는 초안에 붙였던 방어적 종결문, 파일·시트 안내, 반복된 수치 해설, 사용자가 삭제한 표현이 남거나 재삽입되었는지 원문과 대조한다. 키워드 검출은 후보를 찾는 용도이며 자동 삭제 기준이 아니다. 필요한 방법·근거는 유지하고, 점검 결과나 체크리스트를 제출 본문에 덧붙이지 않는다.
