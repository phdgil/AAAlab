# 발표자료 기준

## 제목과 용어

- 제목은 문장형으로 쓰지 않는다. 대상과 비교·결과·쟁점이 드러나는 간결한 명사구로 쓴다. 예: “농도가 높아질수록 생존율이 감소합니다” → “농도별 세포 생존율”. “농도제안”처럼 무엇을 제안하는지 알 수 없는 제목도 피한다.
- 한 개념에는 한 명칭을 사용한다. 청중에게 익숙한 표준 전문용어와 사용자가 지정한 용어를 유지하고, 필요하면 처음에 한국어 설명을 병기한다. 쉬운 표현으로 바꾸다가 cross-validation 같은 분석 방법의 뜻을 흐리거나, 이미 정의한 개념을 다른 이름으로 다시 소개하지 않는다. 영어 사용 자체를 목표로 삼지 않는다.
- `use_for_model`, `cutA` 같은 내부 변수명·불투명한 약칭은 의미가 드러나는 표현으로 바꾼다. 표준 전문용어와 내부 식별자를 구별한다.

## 구성과 필요한 설명

- 정식 발표자료의 표지에서는 발표자·소속 등 필요한 기본 정보를 확인한다. 기존 자료에서 확인할 수 있는 내용을 먼저 찾고, 확인되지 않은 신원을 만들지 않는다.
- 청중의 이해에 필요한 근거·데이터·관계를 중심으로 구성한다. 발표 시간과 요구 조건 안에서 자료의 양에 맞춰 장수를 정한다. 임의의 장수를 채우려고 슬라이드를 만들지 않는다.
- 집합과 증감 수치는 무엇을 센 값인지 설명한다. “기존”, “추가”, “고정”만으로 집합을 구별하지 말고 출처·선정 기준·역할과 집합 간 관계를 필요한 만큼 제시한다. 학습·평가 집단과 교차검증 분할을 구별하고, 활동성별 구성과 출처별 구성처럼 다른 분류 축을 혼동하지 않는다.
- 자료 추가·제외와 고정 집단의 정의는 결과를 이해하는 데 필요한 방법 정보다. 간결함을 이유로 생략하지 않는다. 근거가 부족하면 프로젝트 자료를 확인하고, 그래도 해결되지 않은 정의는 필요한 자료나 설명을 요청한다. 확인된 내용은 먼저 정리하고 미확인 항목 때문에 전체 작업을 중단하지 않는다.
- 반복 조건은 한 번 설명하고 이후에는 비교할 데이터와 달라진 점을 보여준다. 긴 문단을 도식으로 옮길 때는 개념 간 관계가 실제로 드러나게 한다.
- 면책성 문구, AI에게 준 작업 지시, 제작 과정 설명을 슬라이드에 넣지 않는다. 해석을 바꾸는 자료 범위나 조건은 관련 표·그림 가까이에 구체적으로 표시한다.

## 결과 해석과 보고 관점

사용 조건이 정해진 결과는 해당 조건과 그 안의 결과를 우선 설명하고, 전체·조건 밖의 결과를 구별해서 비교한다. 포함 비율·평가 수와 불리한 지표도 유지한다. 성능이 높은 부분집단만 골라 보여주거나, 민감도·특이도·MCC 등의 변화를 확인 없이 모두 “정확도 향상/하락”으로 바꾸지 않는다.

보고 목적에 맞춰 본문과 부록을 모두 살펴 전체 흐름을 구성한다. 작업한 시간 순서나 뒤늦게 추가한 순서대로 나열하지 않는다. 이미 있는 분석 결과는 통합해 정리하고, 단계별 계획은 전체 계획 안에서 완료·진행·예정 상태를 사실대로 구분한다. 확인되지 않은 후속 작업을 완료 성과로 바꾸지 않는다.

이전 자료를 통합·축약할 때는 원자료의 핵심 주장·방법·근거 그림·완료 결과가 어디에 반영되는지 대조한 뒤 본문·부록·제외를 결정한다. 근거 그림의 축·단위·범례·출처도 보존한다. 작업 로그와 해시는 줄이되, 필요한 과학적 근거까지 숫자 요약만으로 대체하지 않는다. 이미 반영된 내용은 중복 추가하지 않는다. 서로 다른 시점의 모델·평가집단·검증 설계·적용범위의 정의와 계산법은 구별하고, 과거 기준이나 성능을 현재 결과에 그대로 혼합하지 않는다.

## 시각 표현

색상은 범주 구분·비교·강조 등 설명할 수 있는 역할에 사용하고 같은 의미에는 같은 색을 유지한다. 목적 없는 색 혼합·장식·그라데이션·아이콘을 추가하지 않는다. 무채색만 사용하라는 의미는 아니다. 중요한 정보가 바로 보이도록 대비와 강조를 사용한다.

도식의 선·화살표·배치는 실제 관계를 표현해야 한다. 서로 다른 개념의 아이콘은 구별 가능하게 만들고, 비교할 항목의 시각적 기준을 맞춘다. 작은 글씨로 내용을 욱여넣기보다 정보를 나누거나 관계를 시각화한다.

## 제출 전 점검

제목과 용어의 일관성, 표지의 기본 정보, 처음 등장하는 집합의 정의, 결과의 적용 조건과 지표를 점검한다. 각 색·도형·아이콘이 어떤 정보를 전달하는지 확인하고 역할 없는 요소는 뺀다. 중복 텍스트와 면책·작업 설명을 제거하되 필요한 정의까지 삭제하지 않는다. 기존 자료를 수정할 때 사용자가 직접 조정한 서식을 보존한다.

발표자 노트 전체 삭제, 특정 배경색, 실험 추가 금지 등 개별 작업의 조건은 현재 요청이 있을 때 적용한다.
