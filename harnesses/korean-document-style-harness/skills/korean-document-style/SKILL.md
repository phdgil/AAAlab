# 한국어 문서·발표자료 작성 기준

DS의 반복 피드백을 반영하는 개인 작성 기준이다. 일반적인 보고서·발표자료 템플릿보다 이 기준을 우선하되, 현재 사용자가 지정한 목적·독자·제출 양식을 따른다. 파일 생성·편집은 해당 형식의 스킬과 함께 수행한다.

- 보고서·논문 원고의 작성 또는 문구·구성 수정: [보고서·논문 기준](references/reports.md)만 읽는다.
- 발표자료의 작성 또는 문구·구성·시각 표현 수정: [발표자료 기준](references/slides.md)만 읽는다.
- 두 결과물을 함께 요청한 경우에만 두 기준을 읽는다. 단순 변환·검색·내용 설명에는 적용하지 않는다.

제출 직전에 해당 기준으로 결과물을 점검하고 직접 수정한다. 점검 과정이나 체크리스트를 결과물에 덧붙이지 않는다.

사용자가 작성 방식에 대한 피드백을 주면 현재 요청한 범위의 결과를 먼저 제공한다. 직접 수정 요청이면 결과물을 고치고, 검토·수정 계획만 요청했다면 문서·슬라이드 원본을 수정하지 않는다. 개인 기준 갱신이 필요할 때만 [피드백 기록](maintenance/feedback.md)을 읽어 그 파일의 갱신 절차를 따른다. 평소 작성 작업에서는 과거 피드백 원문과 변경 이력을 읽지 않는다.

이 스킬의 개선을 요청받으면 위 상대 링크로 기록 위치를 직접 찾는다. 사용자가 기록 파일명이나 경로를 말할 필요는 없다.
