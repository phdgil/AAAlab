# 작성 기준 피드백 기록

이 파일은 공개용으로 일반화한 기록이다. 원문 세션·문서·개인 경로·연구 수치는 포함하지 않는다. 일반 작성에서는 읽지 않고 기준을 개선할 때만 읽는다.

## 갱신 절차

1. 실제 사용자가 직접 준 피드백과 문서에 인용된 내용을 구별한다.
2. 날짜, 짧은 피드백 요지, 유형, 적용 대상, 상태를 기록한다. 전체 대화는 복사하지 않는다.
3. 명시적인 일반 선호는 반영한다. 특정 문서 조건은 그 작업에만 적용하고, 반복 근거가 있을 때 일반 기준 후보로 올린다.
4. 이전 기준과 상충하면 대상·독자·목적을 좁혀 함께 만족할 수 있는지 확인한다. 조용히 이전 기준을 뒤집지 않는다.
5. 해당 references 파일만 필요한 만큼 고친다. 전역 AGENTS에 중복 추가하지 않는다.
6. 현재 작업이 계획 요청이면 원본을 수정하지 않는다. 적용 후 필요한 근거 누락과 동일 피드백의 재발 여부를 점검한다.
7. 공개할 때는 새로 수집한 기록에서 개인·연구 정보를 제거한다. 로컬 원문 이력을 공개본으로 덮어쓰지 않는다.
