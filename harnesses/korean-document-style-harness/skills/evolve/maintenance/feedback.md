# evolve 자체 변경 기록

이 파일은 공개용 일반화 기록이다. 다른 스킬을 개선할 때에는 그 스킬의 기록을 사용하고, evolve 자체를 고칠 때만 이 파일을 읽는다.

## 유지보수

날짜·관찰·일반화 원리·수정 파일·검증 근거를 짧게 남긴다. 원문 세션과 결과물의 민감 정보는 로컬에서 관리한다. 공개 시에는 별도 정제본을 만들고 로컬 원문 이력을 덮어쓰지 않는다.

| 날짜 | 관찰과 원리 | 수정 대상 | 상태 |
|---|---|---|---|
| 2026-10-29 | 사용자가 기록 경로를 기억할 필요 없이 대상 SKILL의 상대 링크로 탐색 | Phase 1, 4 | 반영 |
| 2026-10-29 | 피드백 기록은 개선할 때만 읽어 일반 작성의 불필요한 문맥 사용을 줄임 | Phase 4 | 반영 |
| 2026-10-29 | 색·굵기·이탤릭 주석과 기존 강조를 구별하고 위치를 확인 | Phase 1 | 반영 |
| 2026-10-29 | 하네스 개선·계획 요청과 결과물 직접 수정을 구분 | Phase 3 | 반영 |
| 2026-10-29 | 구조·참조를 검사하고 트리거 변경 시 양성·근접 음성 사례 검토 | Phase 4 | 반영 |

반영은 절차 변경 상태다. 사용자 피드백 감소에 대한 실증 결과는 포함하지 않는다.
