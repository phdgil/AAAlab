# 합성 평가 사례

아래 사례는 검증용으로 새로 만든 입력이다. 실제 연구 결과나 과거 세션의 인용이 아니다. 실행 결과를 기록하기 전에는 통과했다고 표시하지 않는다.

| 문서에서 날짜만 찾아줘 | 작성 기준 적용 제외 |
| Python 함수 문서를 작성해줘 | 작성 기준 적용 제외 |

## 결과물 품질과 범위

1. 제목 “처리 시간이 증가하면 처리량이 감소합니다” → “처리 시간별 처리량”. 본문에서 비교 근거는 유지한다.
2. “참고용이며 정확성을 보장하지 않습니다”는 삭제한다. “측정 장비가 다른 표본은 비교에서 제외했다”처럼 해석에 필요한 조건은 유지한다.
3. 합성 집단 A의 성능이 높지만 포함 비율이 작다면 집단 정의·포함 비율·전체 결과를 함께 제시한다. 이를 무조건 “정확도 향상”으로 바꾸지 않는다.
4. 추가 자료를 통합하면 핵심 방법·그림·완료 결과를 본문·부록·제외에 대응시킨다. 과거 평가 설계를 현재 성과와 혼합하지 않는다.
5. 빨간 굵은 이탤릭 주석 검토와 수정 계획만 요청받으면 해당 주석을 확인하고 기준·계획을 갱신한다. 원본 PPT는 수정하지 않는다.
6. 매 슬라이드에 다른 색을 쓰라는 현재 요청이 있으면 설명할 수 있는 역할을 부여한다. 개인 기준으로 무채색만 강제하지 않는다.
7. 제목 “왜 표본을 나누나” → “표본 분할 기준”, “결과: 온도가 오르면 수율이 준다” → “온도별 수율”. 질문이나 연결 문장은 부제목으로 옮긴다.
8. 합성 강의 자료가 첫 세부 단계부터 시작하고 선행 슬라이드에 아직 정의하지 않은 용어가 모여 있다면, 일상어로 쓴 전체 그림을 먼저 두고 번호 순서로 부분을 다루며 원문 전체 도식은 복습으로 옮긴다.
9. 한 슬라이드가 아직 설명하지 않은 구성 요소를 보여 주고 “나중에 설명”이라고 적었다면, 그 요소를 빼고 필요한 이유가 생기는 슬라이드에서 처음 등장시킨다.
10. 설명이 발표자 노트에만 있으면 본문으로 옮기고, 글자가 15pt 아래로 내려가면 슬라이드를 나눈다. 노트 자체는 삭제 요청이 없으면 남긴다.
11. 실습 슬라이드의 설명용 숫자는 실제 실행 출력으로 바꾸거나, 실행할 수 없으면 그림 가까이에 가상값임을 표시한다.
12. 주제와 연결되지 않는 최신 제품 사례가 여러 슬라이드에 곁가지로 들어 있으면 청중이 실습에서 쓰는 대상의 사실로 바꾼다.
13. 합성 강의의 한 단원이 세부 슬라이드부터 시작하고 방향이 마지막 정리 표에서야 드러나면, 단원 첫 슬라이드에 답할 문제와 번호 붙인 하위 순서를 두고 제목에 같은 번호를 붙인다.
14. 개념 이름이 제목에 먼저 나오고 예시가 뒤따르면, 예시의 현상과 원인을 먼저 보이고 이름은 마지막에 붙인다.
15. 합성 표에 예측 도구의 출력값과 문헌값이 표시 없이 섞여 있으면 값마다 예측·문헌을 구별해 표시한다.
16. 복잡한 주 예제 대신 단순한 보조 예시로 개념을 보여 주는 것은 허용한다. 단, 주 예제의 어느 부분과 같은지 잇는 문장이 없으면 추가한다. 이전 회차 참조가 슬라이드마다 반복되면 이해에 필요한 곳만 남긴다.

## 보고서 면책성 표현의 회귀 사례

아래 입력은 모두 합성 사례다. 문장 자체의 키워드보다 함께 주어진 문맥으로 판단한다.

| 입력·문맥 | 기대 결과 |
|---|---|
| 방법에서 반복 횟수와 평가 대상을 명시했다. 결과 뒤에 새 근거 없이 “일반적 우월성이나 통계적 유의성을 주장하지 않는다”를 덧붙였다. | 뒤의 방어적 종결문 삭제. 반복 횟수·평가 대상·관찰 결과는 보존. 유의한 차이라는 새 주장은 추가하지 않음. |
| 서로 다른 두 평가집단의 정의·방법·결과를 각각 제시하고, 다시 “하나의 성능 순위로 합치지 않는다”고 맺었다. | 중복 총평 삭제. 집단별 정의와 결과를 하나로 합치지 않음. |
| 본문에 “정리.xlsx의 집계 시트에 수록하였다”와 학술 문헌 인용이 함께 있다. 내부 파일 안내는 제출 양식상 필수가 아니다. | 내부 파일·시트 안내만 본문에서 제외. 문헌 인용과 원자료 출처는 보존. |
| 표에서 집합 간 중복과 후보·실제 사용 수를 정의했다. 뒤 문단이 같은 구분과 과거 파일 복원 이력을 반복한다. | 반복 설명 축약. 표의 집합 정의와 현재 수치는 보존. |
| 일부 평가자료가 모델 선정에도 사용되었다는 사실이 유일하게 한 문장에 있다. | 필요한 방법 사실로 한 번 유지. 문구 정리를 이유로 독립검증이라 쓰거나 해당 사실을 누락하지 않음. |
| 사용자가 최종본에서 방어적 총평을 삭제했다. 과거 생성 스크립트에는 그 문장이 남아 있다. | 최종본 기준으로 수정. 원문 또는 같은 뜻의 방어적 문장을 재삽입하지 않음. |
| 사용자가 지정한 두 비교 파일의 내용이 같고, 별도 보존본에만 수정 전 문구가 있다. | 두 지정 파일의 차이가 없다고 명시. 보존본을 사용하면 별도 비교임을 밝힘. 삭제 이력을 지어내지 않음. |
| 원고의 임계값 표시가 0.638217에서 0.64로 바뀌었지만 문구 정리만 요청되었다. | 면책 삭제와 별개인 표시 변경으로 분류. 실행 설정·성능을 바꾸지 않음. |

## 다음 실행의 관찰 항목

동일 유형의 재수정 횟수, 필요한 근거의 누락 여부, 현재 요청 범위 준수를 기록한다. 결과가 개선됐다는 판단은 실제 산출물 검토와 반복 실행 근거가 있을 때만 남긴다.
