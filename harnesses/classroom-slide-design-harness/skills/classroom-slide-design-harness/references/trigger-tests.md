# Invocation and regression scenarios

These are review cases, not a claim that an agent benchmark has been run.

## Should use the harness when explicitly requested
1. Use this harness to shorten my undergraduate introduction to 17 minutes.
2. Redesign these English slides for students who struggle with English.
3. Use classroom-slide-design-harness to remove the repeated three-box format.
4. Revise slide 7 with verified evidence and rerender only what changed.
5. Set up a reusable course slide-design process based on the approved deck.
6. Adapt this visual-first practical lesson to another subject.
7. Improve this deck's color emphasis; a uniform theme is not important.
8. Use the harness to incorporate the latest teacher feedback without extending the lecture.

## Should not trigger deck changes
1. What does this enzyme do? → answer the question.
2. Rename the spreadsheet columns. → edit the spreadsheet only.
3. List the hyperlinks in this PPTX. → extraction only.
4. Is this slide's claim supported? → read-only review unless edits are requested.
5. Explain AC50 versus IC50. → explanation, not a new lecture.
6. Upload this private workbook. → establish the sharing boundary; a harness is not authorization.
7. Install PowerPoint on my computer. → installation task, not automatic package or deck mutation.
8. Generate a press-release presentation for executives. → a different audience; do not silently apply undergraduate defaults.

## Acceptance scenarios
- **New lesson:** one brief, practical task, appropriate visual forms, editable deck, rendered images, explicit review verdict, source files unchanged.
- **Partial revision:** retain unrelated user edits; change only the requested content and its dependencies; rerender and check the affected slides.
- **Unavailable renderer:** structural audit may pass, but a requested Office render fails with a clear unavailable/error status. No visual approval claim.
- **Wrong source record:** stop the measurement example until identity and endpoint are verified. Do not silently substitute a similar record.
- **Clipping or hyperlink contrast:** recompose or shorten, then inspect a new render; no tiny-font workaround.
- **Protected data:** no product names, student data, local file paths or course-specific datasets appear in a public harness package.
- **Count scope:** one item in two databases can count in both database rows, but only once in the overall union. Inactive experimental results remain results.
- **Repeat feedback:** update the existing local rule and feedback record instead of generating a parallel harness.
