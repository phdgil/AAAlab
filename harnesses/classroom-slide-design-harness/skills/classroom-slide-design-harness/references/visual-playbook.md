# Message-driven visual playbook

View `../assets/layout-atlas.svg` relative to the skill root's references directory for original, data-free schematic examples. It is a reference atlas, not a slide template to copy mechanically.

## Recognition before reading
The slide is a visual instruction surface, not the transcript of the lecture. Let the audience recognize the object, number, contrast or action before asking them to read English. Give the instructor nuance in notes without hiding operating rules students need during practice.

## Choose form from meaning
| Teaching need | Useful form | Avoid |
|---|---|---|
| Pose an unresolved question | A large question with two named inputs and a question mark | A danger icon that implies an answer |
| Explain what students will do | A left-to-right action path: Open → Match → Search → Save | Three paragraphs of objectives |
| Compare databases or tools | Aligned rows with a short job description and clickable names | One repetitive slide per tool |
| Explain two mechanisms | Distinct labeled arrow diagrams | Treating an enzyme as a product in a reaction |
| Establish chemical/object identity | Large genuine structure/image with identifiers | Tiny decorative image beside long prose |
| Demonstrate navigation | Numbered path with real entry and destination links | A fabricated website screenshot |
| Interpret a measurement | Enlarged actual record, highlighted number AND unit, labeled endpoint | A number without target, species or source |
| Explain deduplication | One labeled item appearing twice, then one overall item | Adding database row counts |
| Divide work | People/role nodes connected to one shared deliverable | A wall of role descriptions |
| Start the project | High-contrast action poster, real file link, short checklist | Another summary lecture |

These are choices, not ten compulsory slide templates. A different course should have a different sequence. A three-part comparison can use three elements when genuinely necessary; the rejected pattern is repeatedly forcing everything into three identical text cards.

## Color as emphasis
Message before theme. Change dominant colors and light/dark backgrounds across the deck when it helps attention. Keep a few stable meanings within a diagram while allowing slide-level variation.

Useful starting colors (not a compulsory theme):
- Navy `#102A43`: structure or dark grounding.
- Violet `#6542B5`: a distinct category or question.
- Blue `#1768AC`: navigation or evidence source.
- Teal `#087F8C`: action or comparison.
- Coral `#C94F5B`: a caveat or a number needing attention, not automatic proof of danger.
- Amber `#F2B134`: prompt, numbered marker, or start signal; use dark text.
- Warm white `#FAF7F0`: visual rest, structures, and dense evidence.

Check contrast on the actual background. Target WCAG contrast ratios of at least 4.5:1 for normal text and 3:1 for large text where practicable; these are design checks, not proof that a projector or classroom is accessible. Do not rely on red/green distinctions alone. Label categories. Avoid colored text directly on busy photographs or structures.

## Typography and hierarchy
- Short verb/title → large object/value → labels → source. Do not make every item equally bold.
- Prefer sentence case. Reserve a few capitals for short actions; avoid paragraphs in capitals.
- Use real values and units as a single visual unit. An endpoint such as AC50 must not become IC50 through editing.
- Clickable names should remain readable. Native hyperlink styling can turn intended white text into dark blue on a violet background. Inspect rendered links, not just source XML.
- Arrows should terminate at the thing they explain. Enzymes label reaction arrows; causal claims need actual evidence.

## Science/data lessons
Keep identifiers, species, endpoint, relation, value, units, reported outcome and source together. Distinguish measured versus predicted, inactive versus missing, and blocked access versus no record. Do not count a chemical page as an experimental assay result.

In a chemical-mixture lesson, established primary mechanisms and exploratory targets must be separated. A metabolic-enzyme assay hit alone does not prove mixture synergy or human toxicity. For any domain, generalize the same principle: a plausible link is not an observed final outcome.

## Fast visual review
At contact-sheet scale: is the lecture visually varied, and does it end in work rather than another introduction?
At full size: can students read the source IDs and labels, follow the arrows, and find the requested action?
At project time: can students use the slide without remembering a qualification spoken ten minutes earlier?
